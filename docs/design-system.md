# Design System for Xkadzama Education Platform

**Reference:** [getartcraft.com](https://getartcraft.com/)

## 1. Color Palette (Цветовая палитра)

Дизайн построен на контрасте чистого белого фона и глубокого черного текста с яркими акцентами.

| Role | Hex Code | Usage |
| :--- | :--- | :--- |
| **Primary** | `#000000` | Заголовки, основной текст, границы кнопок |
| **Background** | `#FFFFFF` | Основной фон страниц и карточек |
| **Accent** | `#FF5A00` | Кнопки CTA (Call to Action), активные элементы, иконки |
| **Secondary Text** | `#666666` | Описания, второстепенная информация |
| **Border/Divider** | `#E5E5E5` | Границы инпутов, разделители секций |
| **Hover State** | `#333333` | Состояние наведения на черные элементы |

## 2. Typography (Типографика)

Шрифтовая пара обеспечивает профессиональный и дружелюбный вид.

*   **Headings (Заголовки):** `Inter` или `Manrope` (Bold / 700)
    *   H1: 48px - 64px (для главных баннеров)
    *   H2: 32px - 40px (для заголовков секций)
    *   H3: 24px (для заголовков карточек курсов)
*   **Body (Основной текст):** `Inter` (Regular / 400)
    *   Size: 16px
    *   Line-height: 1.5 (для комфортного чтения длинных текстов)
*   **Small/Caption:** 14px (для подписей под картинками или мета-информации)

## 3. Spacing & Layout (Отступы и сетка)

Система отступов базируется на шаге **8px**.

*   **Base Unit:** 8px
*   **Small:** 16px (внутренние отступы в кнопках, между элементами списка)
*   **Medium:** 32px (отступы между блоками внутри секции)
*   **Large:** 64px - 96px (отступы между крупными смысловыми секциями страницы)
*   **Container Width:** Максимальная ширина контента — 1200px - 1400px (центрировано).

## 4. Components Rules (Правила компонентов)

### Buttons (Кнопки)

*   **Primary Button:** Черный фон (`#000000`), белый текст, скругление углов `8px`. При наведении становится темно-серым.
*   **Secondary Button:** Прозрачный фон, черная обводка (`1px solid #000000`), черный текст.
*   **Accent Button:** Оранжевый фон (`#FF5A00`), белый текст (используется редко, только для самых важных действий).

### Cards (Карточки курсов/статей)

*   **Background:** Белый (`#FFFFFF`).
*   **Shadow:** Очень легкая тень или отсутствие тени (Flat design), вместо этого используются тонкие границы (`1px solid #E5E5E5`).
*   **Image Aspect Ratio:** 16:9 или 4:3 для превью уроков.
*   **Padding:** 24px внутри карточки.

### Inputs (Поля ввода)

*   **Border:** `1px solid #E5E5E5`.
*   **Radius:** `8px`.
*   **Focus State:** При клике граница становится черной (`#000000`) или оранжевой (`#FF5A00`).

## 5. Visual Style Notes

*   **Minimalism:** Избегать лишних декоративных элементов.
*   **Whitespace:** Много "воздуха" между элементами для снижения когнитивной нагрузки ученика.
*   **Imagery:** Использовать качественные, яркие фотографии или минималистичные иллюстрации в стиле ArtCraft.
